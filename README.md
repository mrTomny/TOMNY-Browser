TOMNY Browser
Твой браузер. Твои правила.

TOMNY Browser — самостоятельный модульный веб-браузер, разрабатываемый под брендом TOMNY LABS. Цель проекта — дать пользователю больше контроля над рабочими средами, сетевыми соединениями, загрузками, ресурсами системы и собственными данными.
</div>
Браузер задуман как независимая альтернатива Chrome, Edge и Opera. Он должен полноценно работать сам по себе; взаимодействие с другими продуктами TOMNY LABS будет необязательным.

Статус: активная разработка
Первая планируемая публичная тестовая версия: 0.7.0
Формат первой публикации: тестовая сборка (Pre-release)
Концепт интерфейса

Изображение показывает целевой дизайн, а не обязательно текущее состояние реализованного интерфейса.

В основе визуального направления — тёмная сине-графитовая палитра с бирюзовыми акцентами, вертикальные вкладки и группы, отдельные рабочие пространства, центральная рабочая область и боковая панель состояния сети, загрузок и модулей. Интерфейс должен сочетать выразительный внешний вид с удобством повседневной работы.
Основная идея
TOMNY Browser строится вокруг нескольких принципов:
- Независимость. Для обычного использования браузеру не нужны Афина, AltheraCore, сторонняя ИИ-модель или платный API.
- Контроль пользователя. Настройки профилей, сети, разрешений и подключаемых модулей должны оставаться под управлением пользователя.
- Модульность. Неиспользуемые возможности предполагается отключать без нарушения основной работы браузера.
- Разделение сред. Рабочие и личные данные, разрешения и сетевые конфигурации не должны смешиваться.
- Проверяемая эффективность. Заявления о низком потреблении ОЗУ и ЦП должны подтверждаться сравнительными измерениями, а не только архитектурными планами.
Ключевые направления разработки
Следующие подсистемы описывают целевую архитектуру проекта. Их перечисление не означает, что каждая из них уже работает в версии 0.7.0.
Подсистема	Назначение
TOMNY Environments	Независимые рабочие среды с собственными профилями, вкладками, разрешениями, расширениями и сетевыми настройками.
TOMNY Network Matrix	Управление DNS, VPN и сетевыми маршрутами для сред, сайтов и поддерживаемых загрузок.
TOMNY Transfer Engine	Единый центр обычных, больших и торрент-загрузок с восстановлением поддерживаемых передач.
TOMNY Resource Governor	Наблюдение за расходом ресурсов и управление приоритетами сред и фоновых задач в пределах технических возможностей.
TOMNY State Vault	Сохранение и восстановление состояния вкладок, загрузок, настроек и разрешений после сбоев.
TOMNY Modules	Подключаемые и отключаемые возможности с разграничением полномочий.
TOMNY Context Bridge	Контролируемый канал взаимодействия с внешними ассистентами, в том числе Афиной.
TOMNY Permission Center	Единая точка управления разрешениями сайтов, модулей, расширений и внешних ассистентов.
TOMNY Activity Timeline	История значимых событий: изменений сети, загрузок, разрешений и действий интеграций.
TOMNY Portable Environments	Экспорт и перенос настроек рабочих сред с отдельной защищённой обработкой секретов.


Планируемые возможности
- Использование нескольких независимых профилей и рабочих пространств.
- Поддержка настраиваемого DNS over HTTPS (DoH) без обязательного использования системного DNS.
- Подключаемые VPN-интеграции; среди рассматриваемых сценариев — Happ и Cisco VPN. Их фактическая поддержка должна подтверждаться отдельно.
- Совместимость с расширениями из экосистем Chrome, Яндекс Браузера и Opera — по результатам проверки возможностей выбранного движка.
- Устойчивые загрузки больших файлов и, в перспективе, встроенная работа с торрентами, включая продолжение совместимых задач.
- Восстановление состояния после аварийного завершения без автоматического повторения потенциально необратимых действий.
- Разрешения на доступ к микрофону, звуку, данным страниц и действиям внешних интеграций.
- Необязательные панели или окна для внешних ИИ-сервисов (например, ChatGPT, Gemini и Grok) через обычные пользовательские учётные записи, когда это поддерживается сервисом.
Производительность
Одна из целей TOMNY Browser — рациональное использование ресурсов компьютера. План сравнительного тестирования предусматривает сопоставление с Chrome, Edge и Opera при одинаковых условиях:
- одинаковые вкладки и расширения;
- потребление оперативной памяти;
- загрузка процессора в простое;
- воспроизведение видео;
- фоновые загрузки и восстановление сессий.
Пока результаты таких тестов не опубликованы, проект не заявляет доказанного преимущества в скорости или экономии ресурсов.
TOMNY LABS и внешние ассистенты
TOMNY Browser — самостоятельный продукт, а не оболочка для Афины или AltheraCore. В перспективе браузер сможет взаимодействовать с внешними ассистентами через интерфейс разрешений: пользователь сам решает, какие вкладки, события, данные и действия доступны интеграции.

Отсутствие ассистента не должно ограничивать базовые функции браузера.
Публичные сборки
Первый планируемый публичный тестовый выпуск — v0.7.0. После публикации он будет доступен в разделе Releases этого репозитория.

Для каждого тестового выпуска планируется указывать:

- изменения по сравнению с предыдущей сборкой;

- поддерживаемые операционные системы и требования;
- контрольную сумму SHA-256 распространяемого архива.
Важно: тестовые версии могут содержать ошибки. Перед использованием с важными учётными записями и данными следует ознакомиться с ограничениями конкретного релиза и обеспечить резервное копирование.
